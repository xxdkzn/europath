# 🗺 EuroPath — Пошаговый гайд по запуску

## Что это за файл?
Это твоя инструкция. Читай сверху вниз, делай по шагам.

---

## ШАГ 1 — Установить Node.js (если нет)

Node.js — это движок который запускает наш код.

**Windows:**
1. Зайди на https://nodejs.org
2. Скачай версию с надписью "LTS" (зелёная кнопка)
3. Установи как обычную программу
4. Открой командную строку (Win+R → cmd → Enter)
5. Введи: `node --version` — должно показать v20.xx.x

**Mac:**
```
brew install node
```

---

## ШАГ 2 — Скопировать проект на компьютер

Открой терминал (командную строку) и введи:

```bash
# Перейди в папку где хочешь хранить проект (например Документы)
cd ~/Documents

# Создай папку и перейди в неё
mkdir europath && cd europath

# Скопируй все файлы проекта сюда
# (файлы уже подготовлены, просто скопируй их в эту папку)
```

---

## ШАГ 3 — Установить зависимости

В терминале, находясь в папке проекта:

```bash
npm install
```

Это скачает все необходимые библиотеки (~30-60 секунд).

---

## ШАГ 4 — Создать базу данных (Supabase)

1. Зайди на https://supabase.com
2. Нажми "Start your project" → войди через GitHub
3. Нажми "New project"
4. Заполни:
   - Name: europath
   - Database Password: придумай надёжный пароль (ЗАПОМНИ!)
   - Region: выбери Europe (Frankfurt) — ближе к аудитории
5. Нажми "Create new project" → подожди ~2 минуты

После создания:
6. Зайди в Settings → API
7. Скопируй:
   - Project URL → это SUPABASE_URL
   - anon public → это SUPABASE_ANON_KEY

---

## ШАГ 5 — Создать таблицы в базе данных

1. В Supabase зайди в SQL Editor
2. Нажми "New query"
3. Скопируй ВЕСЬ текст из файла `database/schema.sql`
4. Вставь в редактор
5. Нажми "Run" (или Ctrl+Enter)

Увидишь зелёную надпись "Success" — таблицы созданы!

---

## ШАГ 6 — Настроить секретные ключи

В папке проекта создай файл `.env.local` (ТОЧНО такое название):

```
NEXT_PUBLIC_SUPABASE_URL=https://твой_проект.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=твой_ключ_здесь
```

Замени значения на те что скопировал в шаге 4.

---

## ШАГ 7 — Запустить сайт локально

```bash
npm run dev
```

Открой браузер и зайди на: http://localhost:3000

🎉 Сайт работает на твоём компьютере!

---

## ШАГ 8 — Опубликовать в интернет (Vercel)

1. Создай аккаунт на https://github.com (если нет)
2. Создай аккаунт на https://vercel.com
3. В Vercel: "Add New Project" → "Import Git Repository"
4. Загрузи папку проекта
5. В разделе Environment Variables добавь те же ключи из .env.local
6. Нажми Deploy

Через ~2 минуты получишь ссылку: europath.vercel.app
Позже купишь домен europath.app и подключишь!

## КОШЕЛЬКИ ДЛЯ ДОНАТА (заполнить!)
